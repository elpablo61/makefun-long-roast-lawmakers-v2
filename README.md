One satirical sentence roasting lawmakers who would regulate AI, crypto or the
internet but cannot convert a file to PDF. The program writes the line to
`/output/entry.txt` (152 characters, one sentence).

> Councilman Webb's ordinance requires every crypto wallet to register by
> Friday; his own filing arrived as a .pages file nobody in the building can
> open.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Requires Node 22+. No dependencies, no network.
